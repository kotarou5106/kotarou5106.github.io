# 一、重商主义

## 1. 重商主义的背景

要理解重商主义（Mercantilism），首先必须理解16—17世纪欧洲国家面临的历史环境。

从15世纪末开始，欧洲进入海外扩张时期。美洲贵金属大量流入欧洲，远洋贸易迅速增长，殖民地成为各国争夺的对象。与此同时，法国、英国、西班牙、荷兰等国家不断进行战争，建立更庞大的军队、舰队和行政机构。

这给统治者提出了一个极为现实的问题：国家要想在战争和国际竞争中生存，就必须掌握足够的财富。但财富从哪里来？国家如何使自己比竞争对手更加富有？

重商主义就是在这一背景下逐步形成的经济思想与国家政策体系。它在16—18世纪的欧洲具有重要影响，尤其与中央集权国家的发展密切相关。

重商主义没有一个完全统一的理论体系。不同国家、不同时期的重商主义者，对货币、制造业和贸易的看法存在差异。但他们普遍关心同一个问题：如何通过管理国内生产和国际贸易来增加国家的财富与力量？

## 2. 重商主义的主张

它的经济主张大致可以从三个方面理解。

**第一，扩大出口、限制进口，增加国家掌握的财富。**

在许多重商主义者看来，金银等贵金属是国际支付、战争融资和国家财富的重要基础。国家通过出口商品获得金银，通过进口商品向其他国家支付金银。

因此，政府应当鼓励出口，争取贸易顺差，并通过关税、进口限制等政策保护国内产业。这里还涉及一种国际竞争观念：当各国争夺相对有限的市场和贵金属时，一国获得的财富可能意味着另一国的损失。这种认识使贸易和军事竞争紧密联系在一起。

**第二，鼓励国内制造业，使国家尽量摆脱对外国商品的依赖。**

假设英国进口羊毛，再将羊毛加工成纺织品出口。在重商主义者看来，这比仅仅出口原材料更有利于增强国内就业、制造能力和贸易收入。

因此，政府可以通过税收优惠、特许经营、关税保护等手段扶持本国工业。这一政策在17世纪法国财政大臣让-巴蒂斯特·柯尔贝尔（Jean-Baptiste Colbert）那里表现得尤其典型。英国则通过《航海法》等制度保护本国航运和贸易利益。


**第三，国家必须积极组织经济生活。**

重商主义关注的对象已经超出了货币和商品。它开始将人口数量、劳动者工资、农业产量、制造业水平等都纳入国家治理。

例如，政府希望工人拥有足够的食物，但又希望工资成本保持在较低水平，从而提高出口商品的竞争力，于是，粮价、工资、人口增长、劳动纪律就被联系起来。经济活动逐渐成为国家可以计算、规划和干预的对象。

## 3. 重商主义与粮价

假设一个国家的制造业主要集中在城市。工人每天都需要购买粮食，当粮价上涨时，工人维持生活所需要的工资也会提高。如果制造业工资随之上涨，出口商品的生产成本便可能增加，就会削弱国际竞争力。

因此，重商主义时期的许多政策制定者希望维持低粮价。他们往往使用限制出口、打击囤积、干预价格和储备粮食等行政措施。

但这种政策包含一个潜在矛盾。就是如果粮食价格被长期压低，农民可能无法获得足以支持扩大种植的收益。随着农业投资和播种规模受到抑制，未来的粮食供给反而可能下降。于是，一套旨在防止粮食危机的管制制度，可能制造新的粮食危机。


# 二、重农主义

## 1. 重农主义的背景

18世纪的法国仍然是一个以农业为主要经济基础的国家。农业产量受到天气、土地条件和耕作技术限制，而粮食短缺又是严重的政治问题。与此同时，税收、封建负担以及粮食贸易中的限制，也使农业生产和流通面临许多障碍。

所以国家不断干预粮食市场，仍然不能有效消除短缺，甚至可能削弱农业生产。重农主义者由此开始反思国家管理经济的方式。

**重农主义（Physiocracy）** 主要兴起于18世纪中叶的法国，代表人物是弗朗索瓦·魁奈（François Quesnay，1694—1774）。

魁奈是法国医生、经济思想家，曾在路易十五宫廷任职。1758年，他提出著名的《经济表》（Tableau économique），试图系统说明社会财富如何在不同阶级之间流动和再生产。

“Physiocracy”一词来自希腊语词根，大致表示“自然的统治”。它表达了一项重要主张：社会经济中存在一种自然秩序（Natural Order）。经济运行有自身的规律，统治者需要认识并遵循这种秩序。而这个自然秩序，是农业。

## 2. 重农主义的主张

重农主义认为只有农业真正创造财富，这是重农主义经济学的核心。

魁奈观察到，农业具有一种特殊的物质增殖能力：播下种子、耕作土地，最后可以收获远多于播种量的粮食。当然，这个过程需要劳动、工具、种子和其他投入，但扣除这些消耗之后，农业仍可能留下净剩余。重农主义者把这种剩余称为纯产品（Net Product，法语 produit net）。

假设农业一年获得价值100的总产出，维持生产所需要的种子、工具、劳动者生活资料和其他成本共计60，那么剩余40就是这一简化例子中的纯产品。他们认为，这种净剩余最终源自土地与自然的生产力。

那么，重农主义如何看待制造业？

假设有人将羊毛加工成布匹。布匹当然可能比羊毛卖得更贵，但重农主义者认为，这部分价格增加需要支付工人工资、工具消耗以及其他生产费用，并不因此证明制造业创造了新的社会净剩余。

因此，他们将农业称为生产性部门，将制造业和商业归入所谓的“不生产阶级”。这里的“不生产”绝对不等于没有劳动、没有产品或没有社会用处。它专门指这些部门在重农主义的理论核算中不创造新的纯产品。

按照现代经济学的理解，这显然是一种过于狭窄的生产观。但在当时，它有重要的理论意义：重农主义已经开始试图系统解释社会财富的来源及其再生产条件。尤其重要的是，他们将国家财富的基础从贸易积累，转向了社会生产过程及其剩余。

## 3. 重农主义的《经济表》

既然农业创造纯产品，那么接下来就必须回答：这些剩余如何供养其他社会成员？社会又如何维持下一年的生产？

魁奈在《经济表》中，把社会分成三个主要阶级。

农业生产者取得收成，扣除维持生产所需的投入后，将剩余的一部分以地租形式交给土地所有者。土地所有者购买农产品和制造品，制造业者又需要从农业部门购买粮食和原材料。货币和商品不断在三个阶级之间流动，最终使下一轮农业生产成为可能。

魁奈试图证明，社会经济是一个相互依赖、不断再生产的整体。某个部门的支出会成为另一个部门的收入，而土地纯产品为整个循环提供了剩余基础。因此，《经济表》是经济思想史中早期系统研究社会总产品循环与再生产的重要成果。

## 4. 重农主义与自由贸易

回到原先的粮食问题。如果农业纯产品才是国家财富增长的基础，那么农业生产者就必须获得足够的收益，才能维持和扩大生产。

而政府人为压低粮食价格，恰好可能破坏这一条件。重农主义者因此主张允许价格调整、减少粮食贸易限制、鼓励农业投资，让生产和流通更充分地展开。

这与通常概括为“自由放任”的原则密切相关：Laissez-faire, laissez-passer，即让人们自行行动、让商品自由通行。

但是，这里有一个需要注意的地方：重农主义并不意味着取消国家及其所有权力。魁奈等人仍然强调财产权保护、稳定的法律秩序以及适当的国家税制。重农主义者还主张主要向土地地租形成的纯产品征税，即所谓单一税思想。

从阶级利益的角度看，重农主义也包含明确的政治立场。他们倾向于提高农产品价格、维护土地投资与地租收益，却并不主张农业劳动者的工资同比例增加。所以，重农主义虽然为经济自由提供了重要论证，却并不意味着它追求现代意义上的社会平等。

## 2. 治理术

重商主义与重农主义围绕谷物价格、粮食短缺和自由贸易展开的争论，在经济思想史之外还涉及一个重要的政治问题：当经济活动具有不以统治者意志为转移的规律时，政府究竟应该怎样治理？

福柯在《安全、领土与人口》中重新考察了这场争论，试图揭示经济知识与政治权力之间的历史关系，以及现代国家的治理方式如何发生变化。

### 1. 从考古学到谱系学

如果采取知识考古学的方法，可以考察重商主义与重农主义的经济概念在怎样的历史条件下形成，它们遵循怎样的知识规则。但权力技术的谱系学则进一步追问：这些经济知识如何参与政治实践？它们包含怎样的治理目标和策略，又如何改变权力的实际运作？

这里涉及福柯研究方法中一个更加根本的问题：**为什么我们总是习惯于从国家、监狱、精神病院等现成的制度出发，研究它们的历史与功能，却很少追问这些制度及其对象究竟是怎样形成的？**

以精神病院为例，如果研究始终局限于医院内部的组织、规则和医学理论，就容易忽略那些在医院之外形成的精神病学知识，以及它们与公共卫生、教育和社会管理之间的关系。同样，如果只根据监狱宣称的矫正罪犯的目标评价它的成败，就可能忽略监狱虽然未能实现这一目标，却仍然通过形成和管理违法者群体，在更广泛的权力关系中发挥作用。

由此，福柯提出了三个相互联系的研究方向：**从制度转向权力技术，从功能转向策略，从既定对象转向对象的历史形成。**

第三个转移尤其重要。对于疯癫、犯罪等看起来已经确定的对象，我们不能预先假定它们具有某种跨越历史的固定本质，再去考察不同制度如何认识和处理它们；还需要研究特定的知识、制度和权力实践，怎样使它们成为可以认识、分类和干预的对象。

如果精神病院需要从更广泛的权力技术中得到理解，监狱也需要从规训机制的历史中得到解释，那么为什么研究国家时，反而要把国家当成一个预先存在、具有固定本质的实体，再将各种治理技术解释为国家的职能？

福柯由此将同样的方法运用于国家问题。他不再将国家视为权力分析的当然起点，而是考察各种治理技术如何形成、相互结合，并最终参与塑造现代国家。**国家本身，也成为一个需要通过权力技术的历史加以解释的对象。**

### 2. 国家理性与安全机制

要理解这种变化，首先需要回到十六、十七世纪兴起的国家理性。

随着欧洲领土国家的发展和国家间竞争的加剧，政治治理逐渐形成了一种新的原则：国家具有自身的存在条件与利益，政府必须维持国家的生存，并不断增强国家的力量。

围绕这一目标，国家理性发展出一种广泛的行政管理技术，即“治安”。当时的治安远不止现代警察制度，它涉及人口、劳动、生活资料、公共卫生、商品流通和城市建设等诸多领域，试图通过细密的规章组织社会生活，使国家获得更加充分的财富与力量。

重商主义的粮食管制便体现了这种治理方式。为了维持低粮价、保障城市供给和促进制造业发展，政府对谷物的价格、储存与贸易实施严格管理。但正如前文所述，这些措施可能因为压低农业收益而削弱未来生产，最终产生与治理目标相反的结果。

到了十八世纪，重农主义者及其他支持自由贸易的经济思想家，开始提出不同的治理方案。他们认为，价格、生产、利润和商品流通具有某些自身的规律，政府如果允许价格变化和商业竞争，反而可能通过商人的逐利行为促进粮食供应。

这里发生了一次重要的转变：过去被视为必须压制的价格上涨和私人利益，现在开始被理解为可以利用的经济调节因素。

福柯将这种权力技术称为**安全机制**。它不再以预先禁止一切危险为主要目标，而是试图研究事件发生的条件、概率与总体效果，通过调整现实过程中的各种关系来实现治理。

法律主要通过禁令区分合法与非法，规训通过训练和检查使个人符合既定规范；安全机制则更加关注事物实际运行的规律，以及怎样利用这些规律对整体过程进行调节。

当然，这些权力技术并不存在简单的历史替代关系。安全机制的形成没有使法律和规训消失，反而可能重新组织并扩大它们的使用范围。

### 3. 人口

当政府开始依据粮食供给、价格变化、疾病传播和死亡率等现象的总体规律实施治理时，一个新的政治对象逐渐获得明确地位，即**人口**。

人口不只是某片领土上臣民的数量，也不是许多家庭在数量上的简单相加。它具有自身的出生率、死亡率、疾病分布、迁移趋势以及经济行为。这些现象受到自然环境、社会制度和个人利益的影响，在整体层面表现出某些相对稳定的规律，却无法完全通过君主的直接命令加以改变。

例如，政府不能通过一道法令直接降低整个人口的死亡率，却可以通过改善卫生条件、改变生活环境和推广接种，影响不同群体的疾病风险。

人口因此成为一种既具有自身规律，又能够通过环境和其他条件接受政治干预的现实。

但这一转变也伴随着严酷的政治后果。在支持谷物自由贸易的经济学家所设想的市场调节中，即使自由贸易最终能够缓解整个人口的粮食短缺，仍然可能有部分贫困者因为无力购买高价粮而陷入饥饿甚至死亡。

这揭示了人口治理中的一个重要断裂：**人口整体的安全，可以与某些个体的不幸同时存在。** 当人口整体成为政府追求治理效果的层次时，个体的痛苦与死亡并不必然构成总体治理的失败。

现代权力越来越多地以维护和改善人口生命为目标，却并不因此保证每一个人的生命都得到同等程度的保护。

### 4. 治理术的诞生

人口的形成，也使此前的治理艺术获得了新的发展条件。

在十六、十七世纪，政治思想家曾试图借助家庭治理来理解国家治理，要求君主像家长管理家庭一样，谨慎地管理人民与财富。但家庭的规模和内部关系，显然无法直接成为治理整个国家的模型。

随着人口统计和政治经济学的发展，人们逐渐发现，人口具有无法还原为家庭的独立规律。家庭由此从国家治理的模型，转变为政府了解和影响人口的手段；政治经济学则通过研究人口、生产、财富与领土之间的关系，为治理提供新的知识。

在此基础上，福柯提出了**治理术**的概念。

**第一，治理术是一种特殊的权力技术总体。** 它由制度、程序、分析、反思、计算和策略共同构成，**以人口为主要目标，以政治经济学为主要知识形式，以安全配置为根本的技术工具**。

**第二，治理术指西方历史中治理这种权力形式逐渐取得突出地位的长期趋势。** 在这一过程中，治理逐渐成为政治权力的重要组织原则，并形成了一系列专门的装置和相应的知识体系。主权和规训并没有因此消失，而是与治理形成新的关系。

**第三，治理术还意味着国家本身的治理化过程。** 中世纪以法律和司法关系为主要特征的司法国家，在十五、十六世纪逐渐发展为行政国家，随后又在治理技术的扩展中不断发生变化，形成以人口及其经济和生命过程为重要对象的现代治理国家。


由此，现代国家不再被理解为一个具有固定本质、不断向社会扩张权力的实体。它本身也在各种治理技术、知识和行政实践的形成过程中被不断重新组织。
